# Threads 每日一題草稿

用實戰牌譜出 Threads 每日一題，產生每天要貼的草稿。發文由站長自己來：沒有接 Threads API，也不會自動發。第一則留言由 ChatGPT 寫（Issue #37）。

## 怎麼跑

```bash
pnpm --filter @avalon/server threads:draft                        # 今天（台北日期）
pnpm --filter @avalon/server threads:draft -- --date 2026-11-18   # 指定日期
pnpm --filter @avalon/server threads:draft -- --week              # 從 --date（預設今天）起連續 7 天
# 其他選項：--days N、--out <資料夾>、--no-image
```

輸出放在 `packages/server/threads_drafts/`。這個資料夾不進 git，每天產生三個檔：

| 檔案 | 內容 |
|---|---|
| `<日期>.md` | 給站長複製貼上：① 新貼文、② 第一則留言、③ 串在昨天貼文底下的答案 |
| `<日期>.json` | 同樣的內容加上題目（`pick`）；ChatGPT 把第一則留言寫進 `firstComment.text` |
| `<日期>.png` | 題目圖：座位、你的視角、任務進度、到目前的牌譜、輪到你做什麼 |

已經有 `<日期>.json` 的日子會沿用檔案裡的題目和第一則留言，重跑不會換題。題庫或牌譜連結之後更新也一樣，昨天貼出去的題目和今天公布的答案對得上。

## 每週主題（2026-11-11）

| 星期 | 題目 | 串在昨天底下 |
|---|---|---|
| 週一 | 刺殺梅林（你是刺客，三藍之後輪到你刺） | 週日那題的完整答案 |
| 週二 | 派西維爾思考（派西第 2 局起當隊長的第一次） | 週一的梅林 |
| 週三 | 1-5 尾派（選第二局開紅、之後輪得到 3-5 的局） | 週二派西那題的答案 |
| 週四 | 同一局接到 3-5，引用週三的貼文 | 週三真人派了什麼和純邏輯的理由（幾好幾壞、角色週五公布；站長 2026-11-17 確認照這樣） |
| 週五 | 2-5 尾派（優先選之後輪得到 4-5 的局） | 週三、週四兩題的完整答案 |
| 週六 | 同一局接到 4-5，引用週五的貼文 | 週五真人派了什麼和理由（完整答案週日公布） |
| 週日 | 第五局決策 | 週五、週六兩題的完整答案 |

- **只出實戰：** 題目只從實戰出。題庫 `sim_bank.json` 本來就不含模擬的局，網站牌譜的連結也跳過模擬的貼文。
- **視角：** 尾派題優先用忠臣、派西的視角，沒有才用梅林。
- **選局：** 優先選網站上有牌譜頁的局。同一週不重複出同一局；池子用完一輪之前，每週也不會重複。
- **沒有連著的局時：** 週六改出一題獨立的 4-5，週四同理。

## 草稿的內容

- **① 新貼文（≤ 500 字）：**
  - 主題、你的座位和角色（派西附拇指、梅林附看到的紅、刺客附隊友）、到目前的牌譜、輪到你做什麼、怎麼留言作答、題號。
  - 牌譜太長時，前面幾局只留任務結果和湖，完整牌譜看圖。
  - 最後一行是主題標籤 `#阿瓦隆`（站長 2026-11-17）。
- **② 第一則留言：** ChatGPT 填。草稿附上：
  - 建議的百科文章，用分享網址 `/w/<id>/`，Threads 會顯示預覽卡片；
  - 這一題的關鍵字。
- **③ 答案：**
  - 當時真人派了什麼、幾好幾壞、任務結果；
  - 純邏輯的理由：只用那一家當下看得到的資訊，紅方還有幾種可能、真人這隊在幾種裡全好、全好機會最大的隊；
  - 角色代碼、結果、網站牌譜連結；
  - 最後一行「下一題 →」。

草稿只有座位和牌譜記號，沒有玩家名字。第十個座位寫「0家」。

程式：`packages/server/src/bots/threads/`，包含：
- `plan.ts`：一週的計畫
- `draft.ts`：文字
- `image.ts`：圖
- `generate.ts`：接起存檔與題庫

測試：`src/__tests__/ThreadsDraft.test.ts`。
